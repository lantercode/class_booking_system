# F7.0 原型验收标准（Prototype Acceptance）

> 日期：2026-10-19
> 说明：本文件定义**原型级**验收标准（页面/交互/异常状态），用于产品验收本轮原型；不等于正式功能验收。
> 所有"通过"判定须可复现（原型操作路径 + 检查脚本）。未执行项在 prototype-test-report.md 中如实标注。

## 二、交互验收标准

| # | 交互路径（须逐步可点） | 判定 |
|---|------------------------|------|
| IA1 | 后台框架 → 用户管理 → 编辑用户 → 上传头像 → 保存 | 列表头像随之变化 |
| IA2 | 后台框架 → 右上角菜单 → 个人资料 → 编辑昵称 → 保存 | 顶部昵称同步更新 |
| IA3 | 后台框架 → 教室管理 → 新增/编辑教室 → 上传图片 → 保存 | 卡片封面随之变化 |
| IA4 | 后台框架 → 小程序首页 → 拖动排序/编辑模块 → 保存草稿 → 预览 → 返回编辑 → 发布确认 → 成功 | 顺序与内容生效，状态徽标转为"已发布" |
| IA5 | 同 IA4，但发布走失败分支 | 提示失败且**旧版本保留**（线上态不回退） |
| IA6 | 每个页面均可从导航/上级页进入（无孤立页） | 入口矩阵完整 |

## 三、异常状态验收标准

| # | 异常 | 判定 |
|---|------|------|
| IE1 | 上传格式错误 | 行内提示"仅支持 JPG/PNG/WebP" |
| IE2 | 上传大小超限 | 提示"文件超过 5MB" |
| IE3 | 上传网络失败 | 显示"上传失败 + 重试"，重试可成功 |
| IE4 | 列表加载失败 | `el-result` error + 重试可恢复 |
| IE5 | 空数据 / 搜索无结果 | 空态文案区分（暂无数据 / 未找到匹配） |
| IE6 | 图片失效 | 显示统一占位图，无破图 |
| IE7 | 发布失败 | 提示原因，`published` 保持旧版本 |
| IE8 | 小程序接口失败（预览模拟） | 模块按降级规则处理（隐藏/回落/占位） |

## 四、交付边界验收

| # | 判定 |
|---|------|
| IB1 | 原型为独立目录 `F7.0-.../prototype/index.html`，**未修改** F6.0 或任何既有原型文件 |
| IB2 | **未修改**任何正式业务代码 / DB 模型 / 迁移 / 真实 API / 部署配置 |
| IB3 | Mock 数据均标注「原型模拟数据」；不存在的接口以占位标注，未声称已接通 |
| IB4 | 文档中所有"未确认"项进入 open-decisions.md（含影响与推荐） |
| IB5 | 检查脚本可运行，退出码语义正确（全通过 0 / 有 FAIL 1），测试结果真实可追溯 |

## 五、验收不通过的处理

- 出现 FAIL → 修复原型或修正文档，重跑 `verify-prototype.js` 直至通过，并在 test-report 更新结论。
- 无法在原型阶段验证的（如真实 OSS 上传、真实发布事务）→ 明确标为 **NOT VERIFIED**，不得标 PASS。

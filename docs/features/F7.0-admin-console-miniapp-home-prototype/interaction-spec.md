# F7.0 页面交互规格（Interaction Spec）

> 日期：2026-10-19
> 每页规格含：端·角色 / 入口·出口 / 展示字段·数据来源 / 可点击元素（触发条件→行为→目标页/异常反馈）/ API（仅列已核实或将标注占位）/ 验收。
> 通用约束（所有页面）：四态必备（loading/empty/error/success）；写操作二次确认或明确提示；错误以统一信封 `code≠0 + msg` 呈现；**未确认决策以「待确认(D-F7-xx)」黄签表达**，不画成定论；Mock 数据一律标注「原型模拟数据」。

## 通用：原型导航框架

- 左侧导航：真实 admin-web 共 10 项；**本原型仅渲染本次范围内的 3 项**（用户管理 / 教室管理 / 小程序首页），**图标与真实页面一致**（Element Plus SVG path，非 emoji，`C2`），范围外菜单不展示。点击任一项 → 右侧内容区切换到对应页面（原型内为 `goAdmin(page)` 更新 `STATE.adminPage` 后 `renderAdminPage()`）。
- 顶部右侧用户区：头像 + 昵称（点击展开下拉）。
- 面包屑：`首页 / 当前页标题`。

## P-F7-01 用户管理列表（含头像）〔需求 A〕

- **入口**：左侧导航「用户管理」；**出口**：P-F7-02 弹窗。
- **展示列**：头像（新增）· 昵称 · 手机号 · 教师编号 · 学员编号 · 状态(tag) · 微信绑定(tag) · 注册时间 · 操作。 **保留原有全部列**，仅在首列新增「头像」。
- **数据来源（候选）**：`GET /users`（现有），返回已含 `avatar_url`。
- **可点击元素**：
  - 搜索框（回车/清空/放大镜）→ 重置到第 1 页并刷新；空结果显示「搜索无结果」空态。
  - 角色筛选 / 状态筛选（change）→ 刷新。
  - 分页（current-change）→ 刷新。
  - 「新增」→ 打开 P-F7-02（新增模式）。
  - 行内「编辑」→ 打开 P-F7-02（编辑模式，回填含头像）。
  - 行内「重置密码」「删除」「解绑微信」→ 保持现有二次确认行为（原型模拟）。
- **异常反馈**：加载失败 → `el-result`(error) + 「重试」；头像缺失 → 默认头像占位。
- **验收**：头像列在所有行渲染（含默认头像）；原有搜索/筛选/分页/操作未被移除。

## P-F7-02 新增·编辑用户（头像上传）〔需求 A〕

- **入口**：P-F7-01「新增」/「编辑」；**出口**：保存成功回列表 / 取消关闭。
- **字段**：头像上传区 + 手机号（新增可输入 / 编辑只读）+ 昵称 + 密码（仅新增）+ 角色。
- **头像上传区状态机**（可点击元素）：
  - `空闲`：虚线框 + 「点击上传」→ 触发选图（原型用 Mock 选图，不读真实文件）。
  - `预览`：显示缩略图 + 悬浮「更换」「移除」。
  - `上传中`：进度/loading，按钮禁用。
  - `成功`：显示成功标记，写入 `avatar_url`（Mock）。
  - `格式错误`：选择 `.txt/.gif` → 行内红字「仅支持 JPG/PNG/WebP」。
  - `大小错误`：Mock「大图」→「文件超过 5MB」。
  - `上传失败`：Mock 网络失败 → 「上传失败」+ 「重试」按钮（重试可成功）。
- **取消语义**：编辑模式下点「取消」→ 关闭弹窗，**不修改原头像**（未保存不覆盖）。
- **API（候选）**：`POST /upload/image`（新增，原型仅 Mock）；用户资料保存复用 `POST /users/`、`PATCH /users/{id}`。
- **验收**：能在弹窗内完成 选择→预览→更换→移除→上传中→失败重试 的完整模拟。

## P-F7-03 右上角用户菜单〔需求 B〕

- **入口**：顶部右侧头像/姓名（click）；**出口**：退出登录 / P-F7-04。
- **下拉项**：`个人资料`（→ P-F7-04）、`退出登录`（→ 二次确认后模拟登出）。**保留现有「退出登录」**。
- **异常反馈**：无。
- **验收**：下拉同时含两个入口；退出登录仍有二次确认。

## P-F7-04 个人资料编辑弹窗〔需求 B〕

- **入口**：P-F7-03「个人资料」；**出口**：保存成功回框架（顶部同步）。
- **字段**：头像（可更换）+ 昵称（可编辑）+ 手机号（**只读**，`待确认 D-F7-B2`）+ 角色（**只读** tag）。
- **可点击元素**：
  - 更换头像 → 复用 P-F7-02 的上传区交互。
  - 昵称清空 → 校验失败「昵称不能为空」（行内）。
  - 「保存」→ 保存中 → 成功：关闭弹窗并**同步顶部头像+昵称**；失败：弹窗不关闭 + 「保存失败」提示。
  - 「取消」→ 关闭，不改动。
- **API**：`GET /auth/me`（现有）、`PATCH /auth/me`（现有，白名单 nickname+avatar_url）。
- **验收**：保存成功后顶部头像与昵称即时变化；手机号/角色不可编辑。

## P-F7-05 教室管理（仅卡片视图）〔需求 C〕

- **入口**：左侧导航「教室管理」；**出口**：P-F7-07 弹窗。
- **视图形态**：**仅卡片网格**，**无表格（列表）视图、无视图切换控件**（`D-F7-C2`）。
- **卡片内容**：封面图（16:9，**未设置封面 / 图片失效时统一显示「暂无图片」占位**，不绘制任何默认封面图）· 名称 + 教室编码（小号 tag，已确认新增，`D-F7-C3`）· 位置(待评审) · 设备 · 操作（编辑/删除）。**无状态标签、无容纳人数、无「维护↔启用」按钮**。
- **数据来源（候选）**：`GET /classrooms`（现有；新字段待评审/已确认）。
- **可点击元素**：搜索（input）→ 刷新，空结果提示；编辑；删除（二次确认）。
- **异常反馈**：加载失败 → `el-result` 重试；空列表 → `el-empty`；搜索无结果 → 专用空态；图片加载失败 → 占位图（`D-F7-E7`）。
- **验收**：卡片视图四态齐全；**封面图未设置 → 显示「暂无图片」占位**，封面图失效 → 显示占位；展示教室编码；单页无表格视图与切换控件。

## P-F7-07 新增·编辑教室弹窗（含图片）〔需求 C〕

- **入口**：P-F7-05「新增」「编辑」；**出口**：保存回列表。
- **字段**：教室编码*（必填、租户内唯一，`D-F7-C3`）+ 教室名称* + 封面图上传 + 位置(待评审) + 设备（多选，沿用现有预设）。
- **校验反馈**：编码为空 → 「请输入教室编码」；与其它教室（排除自身）重复 → 「教室编码已存在」；名称为空 → 「请输入教室名称」。
- **图片上传区**：状态同 P-F7-02（预览/更换/移除/上传中/失败重试）。
- **API（候选）**：`POST/PATCH /classrooms`（现有，**需扩展** `code/location/cover_image_url`，`D-F7-C1`/`D-F7-C3`；**不含 capacity**）。
- **验收**：能完成图片 选择→预览→保存 的模拟；编码必填与唯一性校验生效；编辑往返保留原编码。

## P-F7-08 首页管理·模块列表〔需求 D〕

- **入口**：左侧导航「小程序首页」（`待确认 D-F7-D1` 命名）；**出口**：配置抽屉 / 预览 / 发布。
- **模块行内容**：拖拽手柄（`⠿`，HTML5 `draggable`，`D-F7-D2`）· 排序值徽标（圆点数字，1 最靠前）· 模块名称 + 摘要（**不含模块类型图标列**）· 启用开关（`el-switch`）· 状态徽标（`已发布` / `草稿有未发布变更`）· 「编辑」。
- **拖动排序行为**：按住手柄拖动到目标行上方 → 目标行高亮（`drag-over`）；放开 → 该模块落到目标位置，排序值重写为 1..n（连续），并标记草稿为"有未发布变更"；拖拽过程中**不整页重渲染**（避免打断原生 drag）；越界自动钳制到首/末位。
- **可点击元素**：
  - 拖拽手柄 → 拖动排序（放下后重排并重写排序值为 1..n）；保留 ▲▼ 等价的程序化上/下移动函数（键盘/无障碍兜底，首/末位自动拦截）。
  - 启用开关 → 切换 `enabled` 并重绘；未启用行灰显。
  - 「编辑」→ 打开右侧抽屉（P-F7-09~13 按类型）→ 「保存草稿」→ 标记"有未发布变更"。
  - 「预览小程序首页」→ P-F7-14。
  - 「发布」→ P-F7-15。
- **异常反馈**：加载失败 → 重试；发布失败 → 提示且保留旧版本。
- **验收**：拖动排序、启停、编辑、预览、发布入口均可触发并改变状态。

## P-F7-14 小程序首页预览〔需求 D/E〕

- **入口**：P-F7-08「预览小程序首页」；**出口**：「返回编辑」回列表。
- **内容**：手机壳内渲染**草稿**的 5 模块（按 `sort` + `enabled`）；模块隐藏规则（`D-F7-E4`）；图片占位（`D-F7-E7`）；
- **视觉基准**：预览页**复刻真实小程序学员端首页**（`apps/miniapp/src/pages/student/courses/index.vue` + `HomeTabBar` / `AppNavbar`）——暖奶油背景、顶部定位导航栏、Banner（135° 深→浅遮罩 + 金色指示点）、金色 section 标题图标、奶油渐变师资圆形头像、左图右文课程卡、金色圆形播放按钮 + 时长胶囊。**底部 TabBar 采用 F6.0 学员端原型口径 4 Tab（首页/排期/AI 助手/我的，AI 为第 3 个一级 Tab，激活 `#8b7355`），AI 助手入口位于菜单栏、无悬浮 FAB**（对齐 F6.0，`TAB_DEFS` 逐字一致）。差异备案：① 真实 `apps/miniapp` 当前为 3 Tab + `AiAssistant.vue` 悬浮入口（与 F6.0/F7 预览口径不同，不静默取舍）；② 真实端首页无「公告」模块（原型新增）。
- **标注**：页面显著标注「原型模拟数据 · 预览的是草稿，未发布」。
- **异常反馈**：模拟"接口失败"开关 → 模块降级（师资/课程回落真实 API、纯配置模块隐藏，`D-F7-E3`）。
- **验收**：预览反映草稿的真实顺序与启停；停用模块不出现；返回编辑回到列表。

## P-F7-15 发布确认与发布结果〔需求 D/E〕

- **入口**：P-F7-08「发布」；**出口**：结果后回列表。
- **流程**：二次确认弹窗（列出将发布的模块摘要）→ 「确认发布」→ 发布中 → **成功**（`已发布` 状态更新，含 version/时间）/ **失败**（提示失败原因 + **保留旧版本**，`D-F7-E2`）。
- **可点击元素**：确认发布 / 取消 / 失败场景切换（原型为演示提供"模拟发布失败"开关）。
- **验收**：成功与失败两分支均可演示；失败后线上仍为旧版本（状态徽标不回退）。

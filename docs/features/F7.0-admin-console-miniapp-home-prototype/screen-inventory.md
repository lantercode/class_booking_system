## 二、状态归属说明（避免重复建页）

- **P-F7-05** 为**单一视图页面**（卡片网格）；原「表格视图 P-F7-06 + 视图切换」已按 `D-F7-C2` 取消，不再作为页面/视图存在。
- **P-F7-09 ~ P-F7-13** 共用**同一右侧抽屉壳**（`el-drawer`），仅内部表单随模块类型不同；不算 5 个独立页面。
- **P-F7-16** 不是一个独立页面，而是**跨页异常状态集合**（在 01/05/07/08/15 中以状态分支呈现）；单列便于验收盘点。
- **P-F7-02 / P-F7-07** 分别为用户弹窗、教室弹窗，字段不同、不可合并。

## 四、入口与出口关系（每个页面均有明确入口，无孤立页）

```
后台框架（左侧导航 + 顶部用户区）
 ├─ 用户管理(P-F7-01) ──新增/编辑──▶ 用户弹窗(P-F7-02 ─头像上传─▶ 保存)
 ├─ 教室管理(P-F7-05 仅卡片视图) ──新增/编辑──▶ 教室弹窗(P-F7-07 ─图片─▶ 保存)
 ├─ 小程序首页(P-F7-08)
 │     ├─编辑模块──▶ 配置抽屉(P-F7-09/10/11/12/13) ──保存草稿──▶ 回列表
 │     ├─预览────▶ P-F7-14 小程序首页预览 ──返回编辑──▶ 回列表
 │     └─发布────▶ P-F7-15 发布确认 ──✅成功 / ⚠️失败(保留旧版)──▶ 回列表
 └─ 顶部用户区(P-F7-03) ──个人资料──▶ P-F7-04 弹窗 ──保存──▶ 顶部头像/昵称同步
```

- 发布后的预览（P-F7-14）呈现学员端首页最终组合（Banner / 师资 / 推荐课程 / 舞蹈视频 / 公告），手机壳视觉复刻真实 miniapp 学员端首页。
- 异常状态（P-F7-16）在主流程各节点可触发。

# F7.0 原型 · 启动说明

> 本目录为 F7.0「后台管理端增强与小程序首页配置」的**可交互 HTML 原型**，**不依赖任何后端、不发起任何网络请求**，全部数据为**原型模拟数据（Mock）**。

## 一、如何运行

### 方式 1：直接打开（最简单）

双击或用浏览器打开本目录下的 `index.html` 即可。原型为**单文件**（内联 CSS + 内联 JS + 内联 SVG 图片 dataURI），**离线可运行**。

### 方式 2：本地静态服务（推荐，行为与真实部署一致）

在仓库根目录执行任一：

```bash
# Python
python3 -m http.server 8080 --directory docs/features/F7.0-admin-console-miniapp-home-prototype/prototype

# Node
npx serve docs/features/F7.0-admin-console-miniapp-home-prototype/prototype
```

然后浏览器访问 `http://localhost:8080/`。

> 无需 `pnpm install`、无需构建、无需任何依赖。

## 二、如何自检（可接入 CI）

```bash
node docs/features/F7.0-admin-console-miniapp-home-prototype/verify-prototype.js
```

- 作用：抽取原型内联 `<script>` 做语法检查，并在 DOM stub 下**真实调用原型函数**逐条断言（用户头像上传、个人资料、教室卡片视图、侧栏范围与图标、按钮风格、首页模块/排序/启停、草稿→预览→发布、异常态、交付边界、预览页复刻真实小程序首页）。
- 退出码：**全部通过 = 0**；存在 FAIL 或语法错误 = 1。
- 结果：**106 / 106 通过**（详见 `../prototype-test-report.md`）。

## 四、原型约定

- **主题风格以 F6.0 原型为基准**：F7.0 的 CSS（颜色变量、字体、圆角、阴影、按钮/表格/弹窗/标签/卡片/输入框/toast/侧边栏等组件样式）已逐项对齐到 `docs/features/F6.0-membership-card-prototype/prototype/index.html`，二者属同一套设计系统（后台部分）；F6.0 文件本身**只读参考、未被修改**。
- 上传区采用 **Element Plus 原生上传样式**（虚线「＋ 选择图片」框 + 格式/大小提示文案），空闲态**不再提供「演示 / 选 .txt / 选大图」等调试按钮**；用户对头像/封面「选择图片 → 上传中 → 成功/失败 → 重试 → 更换/移除」的流程可正常演示。
- 页面标题区（`#admin-actions`）的**操作按钮统一采用纯文字、不加图标前缀**（新增 / 预览小程序首页 / 发布 / 返回编辑 / 模拟接口失败等）；列表行内容图标（教室卡片「位置/设备」）改用**内联线性 SVG 图标**，与页面香槟金主题一致。
- 上传流程**不使用 `setTimeout` 自动推进**，而是用上传中态显式的「模拟成功 / 模拟失败」按钮推进状态，保证行为确定、可被 `verify-prototype.js` 同步验证。
- 图片全部为内联 SVG dataURI：教室**占位封面 `ROOM1`/`ROOM2` 仅保留渐变、不叠加任何文案**（`gradCover` 在无 label 时不再绘制文字）；教室**未设置封面**（`r.cover` 为空）与**图片失效**（`BROKEN`）时统一显示「暂无图片」占位（`coverTag` 无图即返回占位，**不再绘制 `roomDefaultCover` 默认封面图**）；用户未上传头像时回落默认头像占位。
- 顶部为「原型模拟数据」标签，明确标注**未接通真实后端**。
- 待确认业务规则在界面中以黄色 `待确认 D-F7-xx` 便签表达（清单见 `../open-decisions.md`）。

## 五、边界声明

- 本原型**未修改**任何正式业务代码 / 数据库模型 / 真实 API / 登录权限租户隔离逻辑。
- 本原型**不覆盖** F6.0 或其它已有原型文件。
- Mock 交互**不代表后端已实现**；后续正式开发须以 `../solution-design.md` 的候选接口与数据模型评审结论为准。

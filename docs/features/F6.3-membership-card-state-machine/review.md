## 3. 设计一致性

- D1 预扣/确认：次卡按排期日预扣；期卡不扣次；取消回补仅次卡 → 一致。
- D4 有效期边界：`expire_at` 当天允许预约/完成；PENDING+`valid_from IS NULL` 可约 → 一致。
- D5 缺席：NO_SHOW 激活 → 按已确认决策实现。
- D9 期卡 PENDING + 首次完成激活 → 一致。
- fail-closed：并发冲突回滚、保持 PENDING → 一致。

# AI Agent 后端转型 · 动手任务清单

> 目标：从「前端 + AI 辅助」转向「AI Agent 后端工程师」。
> 原则：**收敛大模型不确定性的代码自己写**，确定性样板交给 AI。
> 使用方式：按里程碑顺序执行，完成一项勾一项；AI 只承担「AI 可做」列出的部分。

## 分工判定

| 类型 | 谁写 | 本项目例子 |
|---|---|---|
| 不确定性收敛（循环终止、参数校验、容错降级、记忆、召回、权限、成本） | 自己 | `ai/agent/loop.py`、`session.py`、`rag/retriever.py` |
| 确定性样板（DTO、CRUD、迁移、页面、测试骨架、文档） | AI | `schemas.py`、Element Plus 页面 |
| 已跑通的业务规则 | 自己复述并能手写简化版 | 预约扣次、`job_queue` 行锁 |

## 任务 A：手写最小 ReAct 循环（不依赖框架）

- 文件：`apps/api/src/app/ai/agent/loop.py`
- [ ] 自己重写 `AgentLoop.run()`：发消息 → 解析 tool_call → 执行 → 回填 → 再决策，直到 stop 或触顶
- [ ] 亲手处理：非法 JSON 参数、缺必填参数、模型重复调同一工具、工具超时、超过 `max_loops` 的降级文案
- [ ] 写 20 条对抗用例（构造假 LLM 返回），全部有确定行为、无 traceback
- [ ] `_should_retry` 只对白名单只读工具生效
- AI 可做：测试骨架、批量构造 fixture
- 验收：`pytest tests/unit -k agent_loop` 全绿；能讲清「为什么循环必须有预算和终止条件」

## 任务 B：工具分发与容错规范

- 文件：`apps/api/src/app/ai/mcp_server.py`、`ai/agent/loop.py`
- [ ] 定义统一 `ToolOutcome` 协议：成功 / 业务失败 / 瞬时故障 / 权限拒绝
- [ ] `_parse_arguments` 增加 schema 校验，非法入参返回友好错误
- [ ] 写操作幂等 + 用户确认链路（沿用 `action_token.py`）
- [ ] 任意工具异常不回传堆栈、SQL、内部主机名
- AI 可做：把 10+ 个工具批量迁移到该协议
- 验收：同一写操作重复触发只执行一次；异常文案全部业务化

## 任务 C：记忆管理策略

- 文件：`apps/api/src/app/ai/agent/session.py`
- [ ] 设计并实现：滑动窗口 + 摘要压缩 + 关键事实抽取，带 token 预算
- [ ] 明确边界：课时余额、预约状态等实时数据**不进记忆**，只能走 Tool
- [ ] 长对话测试：100 轮后用户核心约束（如「只约周二晚」）仍被遵守
- [ ] 记录优化前后 token 消耗对比
- AI 可做：压测脚本、数据整理
- 验收：约束不丢失 + token 下降有量化数据

## 任务 D：RAG 真实落地（替换 stub）

- 文件：`apps/api/src/app/ai/rag/retriever.py`、`embedder.py`
- [ ] 制度文档切分策略（按条款而非定长），说明切分理由
- [ ] 接入 embedding 与向量库，实现召回 + 重排
- [ ] 自建 50 条 FAQ 评估集，跑出 `Recall@3` 并至少迭代一轮
- [ ] 删除硬编码假数据；检索不混入实时业务数据
- AI 可做：向量库 docker 配置、批量灌库脚本
- 验收：评估集指标可复现，召回率有前后对比

## 任务 E：可观测性与成本控制

- 文件：`apps/api/scripts/ai_trace_stats.py`、`ai_chat_trace` 相关
- [ ] 定义五维指标：工具调用成功率、fallback 率、平均 loop 数、单次会话 token 成本、P95 延迟
- [ ] 给出告警阈值与理由
- [ ] 能解释一次指标波动的原因
- AI 可做：报表排版、SQL 样板
- 验收：一条命令输出五维报表

## 任务 F：综合作业（二选一）

- [ ] 方案 1：语音输入（见 `docs/ai/plans/02-voice-input.md`），串起 A–E
- [ ] 方案 2：多 Agent 拆分（续费预警 / 预约助手），自己设计边界与路由
- 验收：一个可演示的端到端作品 + 设计取舍说明

## 里程碑

- [ ] M0：画出 `/api/chat` 全链路时序图（含 tool 回调），不看代码能复述
- [ ] M1：任务 A + B，20 条对抗用例全绿
- [ ] M2：任务 C，长对话约束不丢 + token 下降有数据
- [ ] M3：任务 D，召回率达标，stub 删除

## 协作约定

1. A–F 核心代码 AI 不代写，只给思路、伪代码、坑点提示
2. 写完后由 AI 做 Review，只提问题清单，本人修改
3. AI 承担样板代码、批量迁移、测试骨架、部署脚本
4. 每个里程碑结束做一次「面试式追问」检验理解

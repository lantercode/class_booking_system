## 2. 需求与已冻结契约

- **D2（2026-10-21 冻结）**：不新增 `EXHAUSTED` 状态，前端以余额徽标表达"已用尽"。
- **口径**：次卡（`card_type=count`）且 `status=1`(ACTIVE) 且 `remaining_credits=0` 视为"已用完"。期卡/无限卡不存在"用完"，仅过期。
- **范围**：
  - miniapp 会员卡列表：已用完的卡展示徽标 + 灰显（已有 `usedUpCards` 分组，需补展示）。
  - miniapp 会员卡详情：已用完时展示"已用完"标识。
  - admin-web 会员卡列表：状态列对次卡余额 0 追加辅助文案"（已用完）"，不新增筛选枚举。
  - booking-confirm 选卡：**不改动**——F6.6 后端 `recommend-card` 已排除已用卡，前端无兜底需求。
- **Out of Scope**：不改 `membership/models.py` 枚举 / Check 约束 / scheduler / 扣次规则；不新增 admin 筛选项；不动 student-web。
- **依赖**：F6.3（余额口径）、F6.6（选卡推荐语义已落地）。

## 4. 关键决策

- 原型 P-M2 为"详情+流水同页"，本次按 backlog 拆为**详情页 + 独立流水页**；原型流水含课程名/排期，后端 DTO 无该字段，已裁剪（不虚构）。
- 列表 Tab 分组沿用 miniapp 既有口径：status 0/1/3 归"可用"，2/6 归"不可用"。
- student-web 不套香槟金主题，沿用自身 `.page-header` + 白卡 + `el-result`/`el-empty` 范式。
- `/membership/cards` 列表不传 `student_id`，依赖后端归属过滤；不使用后端 `status` 参数（axios 数组序列化与后端逗号串契约不一致，改为前端 Tab 分组）。

## 6. 偏差与风险

- 前端 3 处 `api-client` 类型缺口：`MembershipCard` 未声明 `cancelled_at/cancelled_reason`，页面用局部扩展类型读取（技术债 D-F6.11-1）。
- student-web 依赖混合角色端点 `/membership/cards`，若后端未来收紧为 admin-only 会漂移。
- miniapp 页面级 `disableScroll:false` + 去除 `overflow:hidden` 容器以恢复原生滚动，真机行为仍需确认。

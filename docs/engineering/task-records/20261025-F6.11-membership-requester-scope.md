## 1. 背景与目标

`GET /membership/cards/{id}`、`GET /membership/cards`、`GET /membership/transactions` 仅做租户校验，无学员归属校验：任一登录用户可读本租户任意会员卡（含学员 PII）与全租户流水。F6.11 学员端卡详情/流水页面以此为阻塞项，先修后端再暴露 UI。

## 2. M1 风险声明

- **risk_level**：L4（鉴权/越权，跨模块复用 booking 归属范式）
- **产物策略**：本次仅 T6.11.1 安全前置，未交付 F6.11 完整 9 份产物；以本任务记录作为该子任务交付凭证
- **Agent 选择（M2）**：project-architect（方案冻结）+ backend-engineer（实施）；No DB change（已核对），不调 database-engineer；无前端改动

## 3. 契约冻结

路径、query 参数、响应 DTO 均不变 → OpenAPI 无 diff，`packages/api-types` 无需重新生成。

| 端点 | admin / super_admin | 学员及其他角色 |
|---|---|---|
| `GET /cards/{id}` | 本租户任意卡 200 | 本人卡 200 / 他人卡 403 / 跨租户或不存在 404 |
| `GET /cards` | 全租户，可按 student_id 筛选 | 强制本人；显式传他人 student_id → 403 |
| `GET /transactions` | card_id 可选，全租户 | 传 card_id 须为本人卡；不传则聚合本人全部卡（card_ids 不对外暴露） |
